# AI-Powered Support Ticket Classification System

## Project Overview

This project automates customer support ticket classification using Zapier and Google Gemini AI.

When a user submits a support issue through Google Forms:

1. Data is stored in Google Sheets
2. Zapier detects the new entry
3. Gemini AI analyzes the issue
4. AI category is automatically updated in Google Sheets

## Technologies Used

* Zapier
* Google Gemini AI
* Google Forms
* Google Sheets

## Features

* AI-powered ticket classification
* No-code automation workflow
* Real-time Google Sheets updates
* Prompt engineering integration

## Example Categories

* Login Issue
* Payment Issue
* Technical Bug
* Account Access
* General Inquiry

## Workflow

Google Form → Google Sheets → Zapier → Gemini AI → Updated Google Sheet
